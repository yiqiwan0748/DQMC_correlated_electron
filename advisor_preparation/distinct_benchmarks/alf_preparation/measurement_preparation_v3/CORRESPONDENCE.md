## Hamiltonian and finite-time-step identity

The common fixture is a four-site periodic chain, real nearest-neighbor hopping `t=1`, `U=2`, centered chemical potential zero, grand canonical ensemble, `beta=1`, `dtau=.1`, ten slices, exact hopping exponential, and no measured-Green symmetrization. Physical flavor0 is up and flavor1 is down; there is one color per flavor after ALF's `N_SUN=2,N_FL=2` setup conversion. Every exported entry is one physical spin component, with no factor of two, `N_SUN`, translation average, or Fourier normalization.

The user's centered interaction is `U(n_up-.5)(n_down-.5)`. Native ALF Mz uses `-U(n_up-n_down)^2/2`, which differs by the constant `-U/4` per site. This constant cancels in normalized Green functions. Native continuous coupling is `+sqrt(dtau*U)*phi` for up and its negative for down, with Gaussian bare action `phi^2/2`. The Gaussian moment-generating identity therefore integrates each slice exactly to `exp[dtau*U*(n_up-n_down)^2/2]`. The user's discrete Hirsch sum with `cosh(alpha)=exp(dtau*U/2)` gives the same centered interaction after multiplication by the same constant. `check_alf_proof.py` checks the identities on all four local occupation states. The four-valued quadrature HS option is excluded. Source: [native continuous Mz definition](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/Predefined_Int_mod.F90#L149), [Hubbard setup and color conversion](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/Hamiltonians/Hamiltonian_Hubbard_smod.F90#L238).

Native `Tau_m_mod.PROPR` first calls `Hop_mod_mmthr` (left multiplication by the exact hopping exponential), then left-multiplies the onsite HS operators through `Op_mmultR`. Its resulting slice is `B_l=D_l*exp(-dtau*K)`, the user's `AsymExactPropagator` order. `PROPRM1` right-multiplies by `B_l^-1`. Onsite factors commute. `Symm=false` is essential: ALF's `Symm=true` branch applies an additional half-hopping similarity transformation before measuring. Sources: [actual PROPR/PROPRM1](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/tau_m_mod.F90#L210), [hopping multiplication](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/Hop_mod.F90#L145), [operator multiplication definitions](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/Operator_mod.F90#L491).

The executable native proof sets deterministic nonuniform continuous fields **before** ALF's existing UDV/Green initialization. It exports actual `PROPR(I)`, `PROPRM1(I)`, and native hopping multiplication for every slice and flavor, then invokes the actual `Tau_m` traversal on that fixed configuration and stops before the Monte Carlo sweep loop. The checker requires `VK` agreement and an appreciable discrepancy for the incorrect `KV` order. All original propagation, stabilization, HS sampling, and Green routines are unchanged.

## Operators and endpoints

With no overall Matsubara minus sign, the shared channels are:

| Channel | Operator at `0<tau<beta` | `tau=0` storage convention | `tau=beta` |
|---|---|---|---|
| `GT0[i,j,s]` | `<c_i,s(tau)c†_j,s(0)>` | `G00` | `I-G00` |
| `G0T[i,j,s]` | `-<c†_j,s(tau)c_i,s(0)>` | `G00-I` | `-G00` |

For a fixed HS configuration, write `P_tau=B_l*...*B_1`, `P_beta=B_M*...*B_1`, and `G00=(I+P_beta)^-1`. Then `GT0=P_tau*G00`, `G0T=(G00-I)*P_tau^-1`, and the equal-time matrix at that cut is `P_tau*G00*P_tau^-1`. This gives the endpoint identities in the table. Native ALF initializes precisely these channels and advances them with `PROPR`/`PROPRM1` before calling its existing Hamiltonian observer. Source: [native initialization and time traversal](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/tau_m_mod.F90#L86).

The user observer reads `Gup_τ0/Gup_0τ` and the down-spin equivalents immediately after the user's local Sherman–Morrison updates, before stabilization. A separate post-stabilization callback is diagnostic only. It does not substitute a freshly calculated unequal-time matrix for the maintained buffers. In the user forward scan, local HS updates change the configuration as the cut moves. Consequently each endpoint identity is checked against the **contemporaneous** maintained `G00`; a beta sample is never compared with an earlier zero-time configuration. The dense products in `user_buffer_probe.jl` are eligibility diagnostics only, and are never the proposed primary measurement.

## Full matrix and raw bins

Native ALF's standard Green observer averages flavor and spatial channels. The additive Hubbard `ObserT` export instead places every actual native matrix entry into two `Obser_Vec` channels, `P21_GT0` and `P21_G0T`. The flattened index is tau-major, then flavor(up,down), row, column. There are `11*2*4*4=352` complex entries in each channel: 704 complex or 1408 real components overall. The existing native `Print_bin_Vec` writes paired numerator bin averages and the corresponding sign average. It does **not** divide by the sign; downstream analysis must use the paired ratio. `P21_Counts` records the unweighted count at every tau with print divisor one. Original equal-time scalar counters remain limited to the original four observables, avoiding dilution by equal-time measurement calls. Sources: [native Hamiltonian ObserT](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/Hamiltonians/Hamiltonian_Hubbard_smod.F90#L824), [native vector-bin format](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/observables_mod.F90#L760).

`UserMatrixObserver.jl` accumulates the actual maintained initial/pre-stabilization buffers, paired sign sums, and counts in the identical external ordering. Because the user uses moving-cut configurations, it retains a separate denominator for every tau. Native ALF's fixed-configuration traversal has one common sign denominator, which can be repeated across the tau axis when comparing the two packages. No sample, spin, spatial entry, time point, or imaginary component may be silently dropped. Callback references are consumed synchronously; retained arrays are copies or accumulated scalar values, never mutable aliases.

Before any science, the user probe requires exact original-versus-instrumented HS fields, Green buffers, acceptance, log determinants/signs, LDR factors, calculator directions, and next RNG value after each update call. It additionally checks all actual maintained matrices against contemporaneous products. The native ALF proof checks every exported matrix, inverse, hopping matrix, complete time grid and both endpoints. Neither proof alone is P21. Later science still requires genuinely sampled interacting ALF outputs and sampled actual-user outputs, with frozen independent seeds, fixed sampling budgets, simultaneous matrix/time-grid uncertainty and mixing/equivalence gates.

The prepared adapters cover the ordinary user replica-update path in this real-hopping fixture. They do not establish all orbital-mixing, complex-hopping, or Grover-fused unequal-time paths.
