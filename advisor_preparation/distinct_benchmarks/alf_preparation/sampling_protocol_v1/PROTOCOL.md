# P21 sampled ALF–user Green-matrix comparison: frozen candidate

**P21 remains NOT_RUN_AS_DEFINED.** This is a statistical design, not a sampling driver or submission. Both revision3 adapter proofs must pass first. A separate source-closed implementation, an independent timing/precision pilot, and a final budget receipt are required before final sampling. Previous preparations, the revision2 setup failure, and all pilot outputs remain separate evidence. Root owns resource admission and submission; this design makes no new allocation.

The exact catalogue question is whether the complete interacting finite-temperature unequal-time Green matrix agrees with independent ALF AFQMC. This comparison uses actual ALF `Tau_m`/`ObserT` buffers and the user's actual maintained unequal-time buffers; a separately recomputed ED or determinant Green function cannot replace either output. The [revision3 correspondence](../measurement_preparation_v3/CORRESPONDENCE.md) fixes operator, slice, flavor, bin-format, and endpoint conventions. The [ALF paper](https://arxiv.org/abs/2012.11914) is the independent-package reference.

## Fixture, measurements, and eligibility

Use the unchanged revision3 fixture: four-site periodic real-hopping chain, `t=1,U=2,mu_centered=0,beta=1,dtau=.1`, ten asymmetric exact-hopping slices, grand canonical ensemble, one physical up and one down flavor, `Symm=false`, and no checkerboard. ALF's continuous Gaussian Mz field and the user's discrete Hirsch field integrate to the same interaction slice, up to a constant that cancels in normalized Greens. They need not have matching HS configurations or trajectories. The successful proof must establish native `B_l=V_l*K`, the actual chain kinetic matrix, and all normalization/channel identities before this fixture is eligible.

Retain `GT0[i,j,s]=<c_i,s(tau)c†_j,s(0)>` and `G0T[i,j,s]=-<c†_j,s(tau)c_i,s(0)>`, every `tau=0,.1,...,1`, both spins, and all sixteen ordered site pairs. This is `2*11*2*4*4=704` complex or **1408 real components**. `components.csv` is the complete immutable family. There is no spatial, spin, orbital, time-reversal, or Fourier average. The 704 imaginary components are analytically zero for this real fixture but remain in the family and in its multiplicity budget.

Native primary data must come from sampled native continuous fields with `P21_PROOF_ONLY` unset, using the prepared full-matrix observer. The user's primary data are the initial `tau=0` and **pre-stabilization** forward callbacks of its ordinary `update_replica!` path. Post-stabilization buffers and dense products remain diagnostics. The moving-cut user configurations can change with tau; each tau retains its own paired sign denominator. Endpoint checks use that callback's contemporaneous `G00`, never the earlier zero-time configuration. This scope does not cover the Grover-fused, complex-hopping, or orbital-mixing update paths.

Before pilot or final science: require both full revision3 proof receipts PASS, exact original/instrumented user trajectory and next-RNG replay, recorded source/build/provider/runtime hashes, complete time grids, and all proof tolerances unchanged. A successful proof is eligibility, adding zero benchmark completions. The final sampling implementation must additionally demonstrate complete raw-bin parsing and repeatable statistical replay before final sampling; those drivers are not supplied by this design.

## Independent chains and fixed sampling units

Use eight independently initialized chains **per package**. All 32 pilot/final package-chain seeds are fixed in `seeds.json`; pilot and final seeds and the two packages are disjoint. For native serial ALF, write the chain's single positive Int32 seed to a fresh native `seeds` file before startup. Its pinned [Set_random routine](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Prog/Set_random_mod.F90) passes that value to native [RANSET](https://github.com/ALF-QMC/ALF/blob/f4c500cc5d7bcf089400c63e4e75382c558a4ed3/Libraries/Modules/random_wrap_mod.F90). Zero is excluded because it selects a fallback. Seed the user's Xoshiro initializer with the listed user integer. Different seeds are the practical independence construction; they do not prove mathematical independence of pseudorandom streams.

Use fresh working directories and initial configurations, with no `confout`, `RUNNING`, continuation fields, or previous native seed-state files. Do not replace failed chains, select favorable initializations, or discard measured bins. Preserve every chain and failure.

One **cycle** is a forward and reverse HS scan. On the user path it is two successive actual `update_replica!` calls; collect only the forward callback's complete grid. On native ALF it is one existing `NSweep` iteration, including its native forward/reverse scans and one fixed-configuration `Tau_m` measurement. Confirm this scheduling from the pinned main loop in the sampling source closure. Equal cycle counts specify computational budgets, not equal statistical efficiency. Burn and measurement counts below are cycles, not individual user update calls.

## Pilot and a single final budget decision

The pilot uses eight fresh chains per package, 256 burn cycles and 512 measured cycles per chain, in 32 bins of16 cycles. Native ALF runs48 total bins with `NSweep=16`: discard exactly the first16 complete bins as predetermined burn; retain all32 measured bins. User execution makes512 burn update calls and1024 measured update calls per chain. Pilot comparisons are planning diagnostics only and cannot complete P21.

Run both packages sequentially in a one-CPU,3500MB pilot allocation with a candidate10-minute wall cap. Runtime is unmeasured: the cap is a bound, not an ETA. Record startup, per-cycle/bin timing, maximum RSS, all raw bins and all quality diagnostics. A timeout or failed proof/quality/parser gate leaves the pilot unresolved; do not extrapolate a completed scientific result from partial output.

After this independent pilot, select **one** final measured-cycle budget per chain from `[16384,65536,262144]`, using the same budget for both packages. Final burn is4096 cycles per chain and final bins are64. Thus native `NSweep` is256/1024/4096, burn bins16/4/1, and total `NBIN`80/68/65. The user's total calls are `2*(4096+N)` per chain. Selection uses pilot variances and timings only, not the observed package-mean difference:

1. For each nonstructural real component, estimate pilot `v=var(chain_means_user)/8+var(chain_means_alf)/8` after the paired ratio jackknife below.
2. For each candidate N, project `halfwidth=t7(1-.01/(2*1408))*sqrt(4*v*512/N)`. The factor4 inflates variance. The planning critical value is approximately11.8036387713; final intervals use their actual Welch degrees of freedom.
3. Select the smallest N with the maximum projected halfwidth<=.01 (half the equivalence margin), all pilot quality gates passing, measured RSS within3500MB, and a conservative runtime projection no more than120 minutes **per package**. Project time as `2*(measured pilot sampling seconds)*(4096+N)/(256+512)+120 seconds` per package, separately recording startup. Root must set an appropriate fixed wall cap within its resource policy before submitting.
4. If no candidate is feasible, retain NOT_RUN/UNRESOLVED planning status. Freeze the selected N, measured projection, actual cap, source closure and raw pilot hashes in a new final execution receipt **before any final samples**. Do not inspect final data to choose N. There is one final look and no precision extension in this protocol; any later design requires a new declared error budget and preserved original outcome.

The variance projection is a planning heuristic, not a guarantee of coverage or final precision. A pilot failure requires a separately documented revision; this protocol does not silently change burn, seeds, quality thresholds, margin, or uncertainty formulas.

## Estimator and simultaneous equivalence intervals

Keep numerator/sign **sums** per bin. Native `Print_bin_Vec` gives numerator and sign averages; recover sums using its retained unweighted counts and validate every count. Do not divide each bin by its sign and then average those ratios. User output supplies paired sums and separate denominators by tau.

For each chain/component with B measured bins, let `X=sum_b X_b`, `D=sum_b D_b`, `theta=X/D`, and `theta_minus_b=(X-X_b)/(D-D_b)`. Require finite values and `abs(D),abs(D-D_b)>1e-12`. Set `p_b=B*theta-(B-1)*theta_minus_b`; the chain estimate is `mean(p_b)` and its internal diagnostic SE is `sd(p_b)/sqrt(B)` with sample SD. This is the paired delete-one-bin ratio jackknife, including its usual bias correction. No fitted estimator or uncertainty rescaling is allowed.

For each component, let the eight user chain estimates have mean `mu_u`, sample variance `s_u^2`, and the eight independent ALF estimates have `mu_a,s_a^2`. Define `delta=mu_u-mu_a`, `v_u=s_u^2/8`, `v_a=s_a^2/8`, `SE=sqrt(v_u+v_a)`, and `nu=(v_u+v_a)^2/(v_u^2/7+v_a^2/7)`. Use the [Welch interval](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.stats.ttest_ind.html) `delta +/- t_nu(1-.01/(2*1408))*SE`, from pinned SciPy1.17.1 [Student-t quantiles](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.stats.t.html), with an independent incomplete-beta-CDF quantile check. `nu` lies between7 and14 when both variances are positive. Do not pool package variances or pair unrelated chains.

Family alpha is.01 with Bonferroni over **all1408** real components, irrespective of component correlations. These are **nominal, conditional Monte Carlo intervals**: their interpretation assumes stationary, sufficiently mixed chains with approximately normal chain means and independent chains. Mixing diagnostics do not prove those assumptions or a rigorous family coverage theorem. The completed X06 energy95% coverage experiment does not calibrate these extreme-tail Green-matrix intervals.

For all704 structurally imaginary components, retain every raw value and require absolute imaginary bin numerator per recorded sample<=1e-10 in both packages. They are deterministically zero to declared roundoff for the real arithmetic fixture; mark their zero gate explicitly rather than manufacture stochastic precision from a zero empirical variance. They still consume multiplicity budget. A nonstructural component with zero/nonfinite estimated variance or invalid denominator is UNRESOLVED; no ad hoc zero-width interval is accepted.

For each eligible nonstructural component, PASS requires its **whole** interval inside[-.02,.02]. An interval wholly outside that range is a resolved scientific FAIL. An interval crossing a boundary is UNRESOLVED precision. Merely failing to reject equal means is insufficient. Overall P21 PASS requires all1408 component gates and every source/completeness/quality gate. Report the entire component table and simultaneous intervals, including failed/unresolved entries.

## Fixed quality gates and retained evidence

Apply diagnostics independently to each package/component; do not select chains or components. Require:

- Complete source, build, runtime and raw-bin hashes; eight chain IDs, exact seeds, fixed burn/budget,64 bins per final chain; both orders, both spins, all site pairs and11 times; complete native counts and matching user counts.
- All values finite, valid paired denominators, real signs/phases to1e-12, and mean sign>=1-1e-12 in this half-filled bipartite sign-free fixture. Store raw signs and phase deviations even when positivity is expected.
- Contemporaneous endpoint error<=5e-10. Record the user forward/backward stabilization discrepancies and require maximum absolute Green discrepancy<=1e-8. Native numerical/proposal diagnostics are retained; the sampling driver must define and freeze a comparable native stability output before execution rather than assume the user metric applies to ALF.
- Split R-hat<=1.05 on the chain jackknife pseudovalue sequences: split each64-bin chain into two32-bin sequences, use sample within/between variances and `sqrt(max(1,((n-1)*W/n+B_between/n)/W))`. If within variance is effectively zero but between means differ, R-hat is infinite and quality fails. Structural imaginary zeros are handled by their deterministic gate.
- Recompute each chain's jackknife SE after merging adjacent bin pairs, and require `abs(SE_32-SE_64)/max(SE_64,1e-12)<=.5` for every chain. Pilot uses32 and16 bins correspondingly.
- Estimated effective bins summed over the eight chains>=128. For each chain use `z_b=X_b-theta_jackknife*D_b`, `g0=mean((z-mean(z))^2)`, and successive autocorrelations `r_lag=sum(zcenter[1:B-lag]*zcenter[1+lag:B])/((B-lag)*g0)` through `min(B/4,16)`, stopping before the first nonpositive r. Set `Neff=B/(1+2*sum(r))`. For `g0<=eps(Float64)*max(1,max(z_b^2))`, report B and the degeneracy flag; nonstructural zero chain-variance still cannot create an equivalence interval.

Any missing provenance/grid, failed diagnostic, nonfinite interval, denominator problem or unsupported adapter leaves the scientific question UNRESOLVED; deterministic source/convention/proof failures are separately reported as adapter failures. No scientific PASS can survive an eligibility failure. Preserve finite intervals even if quality fails, so the record does not conceal unconditional estimates. Report every diagnostic maximum/minimum and every rejected component.

Final evidence must include all native raw bin text, user raw sums, per-chain resource/seed/configuration receipts, the complete1408-row component report, statistical replay and independent audit, frozen driver/source closure, original pilot outputs and the pre-final budget receipt. Replaying analysis is allowed; changing frozen physics, precision gates, or discarding data after observation is not. This release freezes design choices only; it neither runs ALF science nor promotes P21.
