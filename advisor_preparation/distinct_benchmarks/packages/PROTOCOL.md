# Distinct independent-package tranche01

Frozen before execution on22October2026. This tranche addresses catalogue IDs **P01–P06 andP16**. Seven scientific questions share one small interacting fixture; components of a full observable are not counted as separate ideas. P11,P12,P15 require separate TeNPy/target adapters and remain NOT_RUN.

The fixture is the periodic four-site Hubbard chain, nearest-neighbor `t=1,U=4,mu_uncentered=0,Nup=Ndown=2`. Physical energies are uncentered. Both spins are included in spatial cuts, and logarithms are natural. The oracle must have a unique canonical ground state with gap>1e-8 and residual<1e-9. The user target runs the actual source's `build_space`, `ground_state_lanczos`, `apply_hamiltonian!`, bit helpers and, forP16, existing `renyi2_entropy_sites`. It does not read an oracle eigenvector.

P01 compares traces rho^n andSn for n2,3,4 at A=[0,1]. P02 assembles all user-ED fixed-N4 Sz sectors, resolves fullS² inside degenerate energy subspaces, and compares every physical state/multiplet within6t ofE0. The independent oracle builds the full QuSpin Fock Hamiltonian and spin generators. P03 compares full spin-resolved one-body matrices, natural occupations and projectors of eigenvalue groups separated by1e-7. P04 compares the whole Szz matrix andSzz(q)=sumij exp[iq(i-j)]Cij/L, including contact terms and all four q. P05 compares connected density matrices andN(q), retaining canonical q0. P06 compares complete onsite and bond-singlet pairing matrices with Delta_ij=(c_jdown c_iup-c_jup c_idown)/sqrt2. P16 compares all three purities andI2 forA=[0],B=[2],union=[0,2], directly invoking the user's arbitrary-site entropy function.

Each idea passes only if every component agrees within1e-8 absolute; P01's three power traces use1e-9. No thresholds change after seeing results. Degenerate energy eigenspaces are resolved by projected S²; natural-orbital degeneracy is compared by projectors, not arbitrary eigenvectors. Failure in a noncontiguous fermionic partial trace remains a failure and triggers diagnosis; it is not relabeled as a different observable.

P01–P06 add observable-analysis adapters around the user's ED solver; these observables were not all existing package APIs. That adapter status must remain visible. P16 exercises an existing source API. This tranche validates the specified source-state/Hamiltonian and observable paths against a separately constructed well-known package; it does not imply a DQMC or DMRG measurement was run. TeNPy comparisons and larger fixtures need later manifests.

Primary API sources: [QuSpin spinful basis/operator/partial-trace reference](https://quspin.github.io/QuSpin/generated/quspin.basis.spinful_fermion_basis_1d.html) and [official Hubbard example](https://quspin.github.io/QuSpin/examples/example6.html). QuSpin's pipe separates up/down operator strings; the oracle uses its own operator implementation. Both pairing conventions and canonical ordering are stated explicitly in source. The target's generic Fock action is independently written Julia code; the oracle uses QuSpin contractions and partial traces.

Run each attempt in a new directory. Preserve all outputs, failures, source hashes, package versions and job IDs.
